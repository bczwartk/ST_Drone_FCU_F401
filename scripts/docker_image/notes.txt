Docker image for STM32CubeIDE environment.
The setup uses:
* STM32CubeIDE v1.12.1 - see here: https://www.st.com/en/development-tools/stm32cubeide.html#overview
  Download the STM32CubeIDE binary for Debian and save next to the Docker file as
        st-stm32cubeide_1.12.1_16088_20230420_1057_amd64.deb_bundle.sh.zip
  or modify Docker file to use a different version. 
* Docker image for STM32CubeIDE - see here for starting point: https://github.com/xanderhendriks/docker-stm32cubeide/releases/tag/v9.0
  The Docker file we use was adapter from this one.
